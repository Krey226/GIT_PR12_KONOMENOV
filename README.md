## Описание программы 📋

**Калькулятор** — это учебный проект, написанный на языке *Python*. Программа выполняет базовые арифметические операции: сложение, вычитание, умножение и деление. Проект создан в рамках практической работы по МДК 02.02 и демонстрирует навыки работы с Git, GitHub и разметкой Markdown.

Данные инструкции предоставят вам копию проекта и помогут запустить его на вашем локальном компьютере для разработки и тестирования.

## Необходимые условия ⚙️

Для установки и запуска программы вам потребуется:

- Установленный **Python версии 3.10 или выше**
- Система контроля версий **Git**
- Любой редактор кода (рекомендуется **Visual Studio Code**)

Пример проверки версии Python в терминале:

```
python --version
```

Если команда вернула `Python 3.10.x` или выше — всё в порядке.

## Установка 🛠️

Пошаговая серия команд, которые нужно выполнить для запуска проекта.

**Шаг 1.** Клонируйте репозиторий на свой компьютер:

```
git clone https://github.com/Krey226/GIT_PR12_KONOMENOV.git
```

**Шаг 2.** Перейдите в папку с проектом:

```
cd calculator
```

**Шаг 3.** Запустите программу:

```
python main.py
```

Завершите пример получением некоторых данных о системе — после запуска в консоли появится приглашение `Введите выражение:` и вы сможете протестировать работу калькулятора.
